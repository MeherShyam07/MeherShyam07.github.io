## Preview
Extract the ZIP and open `index.html` in Chrome or Edge.

## Publish free with GitHub Pages
1. Sign in to GitHub: https://github.com/MeherShyam07
2. Create a **public** repository named `MeherShyam07.github.io`.
3. Upload `index.html` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Your site will be available at `https://mehershyam07.github.io` after GitHub finishes deployment.
